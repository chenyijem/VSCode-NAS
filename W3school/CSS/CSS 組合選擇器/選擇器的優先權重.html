CSS 選擇器優先順序權重:

含有 !important 的樣式>行內樣式> ID 選擇器 > Class 類別選擇器 > 元素選擇器 在權重計算中，我們會將選擇器分為三種類型，並計算出它們的個數成為 (a, b ,c) 的形式。 權重的比較順序為 a -> b -> c若前一位數相等才需要繼續往下比，否則就依照大小決定權重順序。 也就是說不管後面兩項如何， (1, n, m) 永遠大於 (0, x, y)權重相同時前面的樣式會被後面的覆蓋
  • a:ID 選擇器 的個數
  • b:Class 選擇器、偽類選擇器、屬性選擇器 的個數
  • c:元素選擇器、偽元素選擇器 的個數
舉例： #myID (1, 0, 0) > .myClass (0, 1, 0) #myID:hover (1, 1, 0) > .myClass::after (0, 1, 1) 通配符 (*) 的權重為 0 含有 !important 的樣式為最優先 行內樣式高於所有權重，但低於 !important 亦即 !important -> a -> b -> * ->繼承的樣式.

例如:p{color:red !important}

如其樣式和其他設定有衝突時,因有important,所以不會被覆蓋

將滑停留在style上的選擇器元素上會彈出權重的資訊窗
