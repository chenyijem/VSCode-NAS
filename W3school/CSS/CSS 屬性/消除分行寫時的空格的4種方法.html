1.有空格 為什麼會有空格產生 行內元素不是寫在同一行 不同行就有空格 我想要分行寫 而沒有空格
2.沒空格 子元素用display:flex 父元素必須清除float影響力,加入clearfloat::after 但當瀏覽器左右縮窄時空格仍會產生 不推薦使用, 推薦子元素用float:left
3.沒空格因加入備註符號在換行頭、尾空格鋸齒寫法,行尾加入<!次行首加入-->這樣做就沒有空格
4.沒有空格 將父元素加入font-size=0 再在子元素設定font-size 即可消除行塊間空白間隔
5.沒有空格 子元素用float:left, 搭配父元素clearfloat::after. 空內容content:''; 及clear: both; display:block 而沒有空格
