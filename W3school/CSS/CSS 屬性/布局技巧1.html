行內塊居中
span 行文字居中X

  1. 行內元素,行內塊元素在父元素中的對齊可以像處理文本對齊一樣用 text-aling,line-height,text-index.

  2. 如何讓子元素在父元素盒中水平居中,a.如子元素為塊div則給父元素加上margin:auto. b.若子元素為行內元素span或行內塊元素則給父元素加入 text-align:center.

  3. 如何讓子元素在父元素盒中垂直居中a.如子元素為塊div則給父元素加上margin:top 值為(父元素content內容器height-子元素總高) /2.讓父元素的height=line-height. 若要精確垂直居中,父元素font-size可設為0,再由子元素設字大小.
