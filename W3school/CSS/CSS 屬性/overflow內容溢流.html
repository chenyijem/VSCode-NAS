默认情况下，溢出是visible可见的，这意味着它不会被裁剪，而是在元素框外渲染：overflow 属性规定如果内容溢出元素框会发生什么情况。
若使用 hidden 值，会剪裁溢出，并隐藏内容的其余部分overflow 属性规定如果内容溢出元素框会发生什么情况。

将溢出值设置为 scroll，溢出将被裁剪，并添加滚动条以在框内滚动。请注意，这将在水平和垂直方向上添加滚动条（即使您不需要它）：

将值 auto 类似 scroll，只是在必要时添加滚动条：当您想更好地控制布局时，可以使用 overflow 属性。

overflow-x 规定如何处理内容的左/右边缘。overflow-y 规定如何处理内容的上/下边缘。x方向就算設為scroll滑桿無法滑動
