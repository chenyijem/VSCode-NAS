:active 伪类实例

注意同一元素多個偽類要依:link,:visited :hover, :active順序排列 才不會前動作效果會被後動作掩蓋,尤其 :active 要放最後面

:active 伪类最常用于 <a >和 <button>元素。

当用户点击链接时，链接会被激活；按钮也是如此。
